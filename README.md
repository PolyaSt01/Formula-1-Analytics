О проекте
Аналитический дашборд по истории чемпионата мира Формулы 1 (1950–2024), реализованный в двух программных средах: Excel и Power BI. На основе открытого датасета с Kaggle.


Содержимое репозитория
БД — исходные данные в формате CSV
F1_Analytics.pbix — дашборд Power BI
F1_Analytics.xlsx — дашборд Excel
О_проекте_и_БД.pdf — документация проекта


Настройка перед использованием
Для корректной работы отчёта после скачивания репозитория необходимо обновить параметр FolderPath в Power Query (Transform Data → Manage Parameters) на путь к папке БД в месте, куда был скачан репозиторий.
